# Todo-list (Лабораторная работа №3)

## Описание
Интерактивный список задач на чистом JavaScript: добавление (кнопка или Enter), удаление, отметка о выполнении с зачеркиванием и фильтрация по статусу («Все», «Активные», «Завершённые»). Счётчик показывает количество оставшихся и выполненных задач.

## Технические особенности
- HTML-разметка задач генерируется в JS через `document.createElement`.
- Данные хранятся в массиве объектов `{ id, text, completed }` и перерисовываются функцией `render()`.
- Использованы методы `map`, `filter`, `forEach`; события — только через `addEventListener`.
- `localStorage` не используется (данные не сохраняются между перезагрузками).
