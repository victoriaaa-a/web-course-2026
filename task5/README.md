# Лабораторная работа №5. Игра Simon (Симон говорит)

## Описание
Компьютер показывает последовательность подсветки 4 цветных секторов, игрок должен её повторить. С каждым успешным раундом последовательность удлиняется на 1 элемент. При ошибке игра заканчивается.

## Технологии
- HTML5
- CSS3 (Grid, анимации, неоновый дизайн, адаптивная вёрстка)
- JavaScript (ES6+, классы, модули, async/await)
- localStorage для сохранения рекорда

## Структура проекта
Проект разделён на модули и классы по принципу разделения ответственности:

- `constants.js` — константы и настройки игры (задержки, ключ localStorage)
- `state.js` — класс `GameState`: управление состоянием игры (последовательности, уровень, рекорд)
- `ui.js` — класс `GameUI`: работа с DOM (отображение статистики, статусов, анимация секторов)
- `game.js` — класс `SimonGame`: основная логика игры (раунды, проверка ходов, старт/конец)
- `main.js` — точка входа, инициализация игры после загрузки страницы

## Функционал
- 4 цветных сектора (зелёный, красный, жёлтый, синий)
- Кнопка START для запуска и перезапуска игры
- Генерация случайной последовательности
- Показ последовательности через `async/await` + `setTimeout`
- Блокировка кликов игрока во время показа последовательности
- Счётчик текущего уровня
- Сохранение лучшего результата (рекорда) в `localStorage`
- Визуальная подсветка секторов с неоновым свечением
- Статусные сообщения (готовность, показ, ход игрока, ошибка)
- Адаптивный дизайн для мобильных устройств

## Как играть
1. Нажать кнопку **START**.
2. Запомнить порядок подсветки секторов.
3. Повторить его кликами по секторам в той же последовательности.
4. При успешном повторении — переход на следующий уровень (последовательность удлиняется).
5. При ошибке — игра заканчивается, показывается достигнутый уровень.
6. Для новой игры нажать **RESTART**.
