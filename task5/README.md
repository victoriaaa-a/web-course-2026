# Лабораторная работа №5. Игра Simon (Симон говорит)

## Описание
Компьютер показывает последовательность подсветки 4 цветных секторов, игрок должен её повторить. С каждым успешным раундом последовательность удлиняется на 1 элемент. При ошибке игра заканчивается.

## Технологии
- HTML5
- CSS3 (Grid, анимации, адаптивная вёрстка)
- JavaScript (ES6+, классы, модули, async/await)
- localStorage для сохранения рекорда

## Структура проекта
Проект разделён на модули по принципу разделения ответственности:
- `constants.js` — настройки игры (задержки, ключи)
- `state.js` — класс `GameState` (данные: последовательности, уровень, рекорд)
- `ui.js` — класс `GameUI` (работа с DOM)
- `game.js` — класс `SimonGame` (логика игры)
- `main.js` — точка входа

## Функционал
- 4 цветных сектора (зелёный, красный, жёлтый, синий)
- Кнопка START/RESTART
- Генерация случайной последовательности
- Показ последовательности через `async/await`
- Блокировка кликов во время показа
- Счётчик уровня и рекорд в `localStorage`
- Неоновый дизайн с градиентным фоном

## Как играть
1. Нажать **START**
2. Запомнить порядок подсветки секторов
3. Повторить его кликами по секторам
4. При ошибке — игра заканчивается, показывается достигнутый уровень
5. Для новой игры нажать **RESTART**
