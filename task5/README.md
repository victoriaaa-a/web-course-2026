# Лабораторная работа №5. Игра Simon (Симон говорит)

## Описание
Компьютер показывает последовательность подсветки 4 цветных секторов, игрок должен её повторить. С каждым успешным раундом последовательность удлиняется на 1 элемент. При ошибке игра заканчивается.

## Технологии
- HTML5, CSS3 (Grid, анимации)
- JavaScript (ES6+, async/await, AudioContext)

## Функционал
- 4 цветных сектора
- Кнопка START для запуска и перезапуска
- Генерация случайной последовательности
- Показ через `async/await` + `setTimeout`
- Блокировка кликов во время показа
- Счётчик уровня и рекорд в `localStorage`
- Звуки для каждого сектора
- Анимация тряски при проигрыше

## Как играть
1. Нажать **START**.
2. Запомнить порядок подсветки секторов.
3. Повторить его кликами.
4. При ошибке игра заканчивается — показывается уровень.
