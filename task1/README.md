# Лабораторная работа №1

Семантическая вёрстка. Страница-резюме.

**Задание:**
- Сверстать одностраничное резюме с блоками: шапка, аватар, о себе, образование, навыки, контакты, навигация.
- Использовать семантические теги: header, main, section, article, nav, footer.
- Раскладка только через Flexbox (float и absolute запрещены).
- Файлы: index.html и style.css в папке task1. Без JavaScript и инлайн-стилей.
- box-sizing: border-box глобально, адаптивность не нужна.
