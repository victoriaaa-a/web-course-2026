# Лабораторная работа №4. Игра «Быки и коровы»

**Цель:** закрепить работу с состоянием, массивами/строками и условной логикой без Canvas.

**Задание:**
- Компьютер загадывает 4-значное число с неповторяющимися цифрами.
- Игрок вводит 4 цифры, после попытки показываются «быки» (цифра на своём месте) и «коровы» (цифра есть, но не на своём месте).
- Валидация: ровно 4 разные цифры, иначе ошибка без засчитывания попытки.
- История попыток, счётчик, сообщение о победе при 4 быках.
- Кнопка «Новая игра» сбрасывает состояние.

**Требования:**
- Логика генерации, валидации и подсчёта — в отдельных функциях, без готовых библиотек.
- Файлы: task4/index.html, style.css, script.js. Без Canvas.
- История рендерится из массива данных, а не через innerHTML напрямую.
