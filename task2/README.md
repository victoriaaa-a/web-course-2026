# Лабораторная работа №2. Адаптивная вёрстка лендинга

**Что было сделано в рамках задания:**
- **Адаптивная вёрстка по методологии Mobile First** с тремя контрольными точками (мобильная до 767px, планшетная от 768px и десктопная от 1200px).
- **Комбинированная раскладка**: макро-сетка крупных блоков реализована на **CSS Grid**, а микро-структура компонентов (карточки, меню) — с помощью **Flexbox**.
- **Интерактивные элементы на чистом CSS**: создано адаптивное меню-«гамбургер» и оформлена форма обратной связи со всеми состояниями (`:hover`, `:focus`, `transition`) без использования JavaScript.
