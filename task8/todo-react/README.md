# Лабораторная работа №8-9: Todo-list на React

## Описание
Приложение Todo-list, переписанное с чистого JS на React. Реализованы компоненты, передача данных через props, фильтрация, сортировка и сохранение в localStorage.

## Технологии
* React (функциональные компоненты, хуки: useState, useEffect, useMemo, useCallback)
* Vite
* CSS
