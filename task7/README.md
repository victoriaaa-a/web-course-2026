# Лабораторная работа №7. Асинхронность: лента постов с бесконечным скроллом

## Описание
Приложение для просмотра ленты постов с сервера. Посты подгружаются порциями по мере прокрутки страницы (бесконечный скролл). Реализован поиск по заголовкам по уже загруженным данным, индикатор загрузки и обработка сетевых ошибок. При достижении конца списка появляется уведомление.

## Технологии
HTML5
CSS3 (Flexbox, стилизация, CSS-переменные, анимации, backdrop-filter)
JavaScript (ES6+, классы, ES-модули, fetch API, async/await, IntersectionObserver)

## Структура проекта
Проект разделён на модули по принципу разделения ответственности (логика работы с сетью отделена от логики интерфейса):

* `index.html` — разметка страницы (лента, поиск, лоадер, контейнер для ошибок).
* `style.css` — стилизация, анимации (спиннер, появление карточек), адаптивный фон.
* `js/api.js` — класс `PostAPI` (запросы к серверу, пагинация, обработка статусов).
* `js/utils.js` — вспомогательные функции (реализация `debounce` для поиска).
* `js/PostApp.js` — класс `PostApp` (состояние приложения, рендер, бесконечный скролл, поиск, обработка ошибок).
* `js/main.js` — точка входа (ожидание загрузки DOM и запуск приложения).

## Функционал
* **Загрузка данных:** подгрузка первой порции постов (10 штук) при старте через `fetch` к `jsonplaceholder.typicode.com/posts`.
* **Бесконечный скролл:** при прокрутке страницы до конца (срабатывание за 100px до низа) автоматически подгружается следующая порция постов. Реализовано на `IntersectionObserver`.
* **Индикатор загрузки:** при ожидании ответа от сервера отображается анимированный CSS-спиннер (пульсирующее сердечко) и текст «Загрузка...».
* **Поиск с дебаунсом:** фильтрация списка по заголовку (`title`) в реальном времени. Фильтрация происходит на клиенте по уже загруженным данным. Дебаунс (задержка 300мс) реализован вручную через `setTimeout`/`clearTimeout` без использования сторонних библиотек.
* **Остановка загрузки:** когда посты заканчиваются (API возвращает пустой массив), подгрузка останавливается и появляется сообщение «Больше постов нет».
* **Обработка ошибок:** при сбое сети (`fetch` завершился ошибкой или `response.ok === false`) пользователю показывается понятное сообщение об ошибке, а в консоль выводится подробная информация.
* **Оптимизация рендера:** карточки постов собираются в `DocumentFragment` и вставляются в DOM за один раз для избежания лишних перерисовок браузера.

## Как пользоваться
1. Открыть страницу — автоматически загрузится первая порция постов.
2. Прокручивать страницу вниз — новые посты будут подгружаться автоматически.
3. Ввести текст в поле поиска — список отфильтруется по заголовкам.
4. При достижении конца ленты появится сообщение о том, что постов больше нет.
